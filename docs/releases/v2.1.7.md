# PaperReader v2.1.7

> 📖 **Read the [User Guide (中文)](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/user_instruction.md) before downloading** — installation, first-run setup, and usage. [中文发布说明](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/zh-cn/releases/v2.1.7.md)

PaperReader v2.1.7 restores translated-PDF compilation in the macOS desktop app and fixes LaTeX-generation and recovery failures reproduced by real PDF inputs.

## What's fixed

- **Finder-launched macOS builds can run XeLaTeX.** When `LATEXMK_PATH` is absolute, PaperReader now adds its directory to the compiler subprocess `PATH`. The detected `/Library/TeX/texbin/latexmk` can therefore launch the sibling `xelatex` binary instead of failing with `sh: xelatex: command not found`.
- **Generated Chinese documents use portable fonts.** PaperReader disables `ctex`'s obsolete platform presets and explicitly selects SimSun, Songti SC, PingFang SC, Noto Serif CJK SC, or FandolSong. Retrying an existing v2.1.6 failure upgrades its saved `translated.tex` before compilation and reuses the completed extraction and translation checkpoints.
- **Local text-layer extraction keeps malformed formula examples compilable.** Currency amounts and intentionally malformed display-math samples are left as escaped prose rather than being paired into invalid nested LaTeX delimiters.
- **PDF math glyphs are normalized.** Split private-use bracket pieces from PDF font encodings are converted into ordinary brackets, and `≪`, `ℓ`, prime, and floor-delimiter symbols receive LaTeX mappings instead of rendering as missing glyphs.
- **Successful strict builds are no longer discarded for a font warning.** Unicode replacement markers introduced by a translation are removed before checkpointing and TeX generation. Other missing-glyph diagnostics remain visible as compile warnings, while only fatal log errors or a PDF requiring the lenient `-f` pass enter automatic recovery.
- **Minimal repair patches tolerate nearby line-number drift.** If a model supplies the exact original text with an offset line number, PaperReader relocates it only when there is one verbatim match inside the compiler-located error window; ambiguous or out-of-window edits remain rejected.

## Compatibility

This is a backward-compatible patch release with no database or data migration. TeX Live with `latexmk` and XeLaTeX remains required for translated PDF generation.
