PaperReader v2.0 combines reader AI workflow, translation reliability and the Windows portable application.

## What's included

- Per-user SQLite history, account/profile settings, persistent document/library chat, literature retrieval and aligned PDF navigation.
- Recovery from incomplete translation batches, long-segment splitting, improved MinerU figures/tables and safe handling of failed PDF compilation.
- Windows 10/11 x64 portable application with the bundled Python backend and built React UI; no separate Python or Node.js installation is needed.
- Release compatibility fixes for same-origin login cookies, PDF/preview credentials, production frontend discovery and legacy MinerU configuration.
- Authenticated artifact downloads that enforce ownership and do not expose the SQLite database or shared chat store.
- Explicit preview/apply import of recoverable v1.0 PDF output folders, preserving existing files and ownership.
- Cross-platform regression CI, actual packaged EXE startup/restart checks, versioned ZIP and SHA-256 checksum.

## Download and run

Download **PaperReader-v2.0.0-Windows-x64.zip**, verify it against the matching `.sha256` file, extract the entire archive to a writable folder and run `PaperReader.exe`. Read the included Chinese usage guide. The EXE is unsigned. Microsoft Edge is recommended; TeX Live with XeLaTeX/latexmk is still needed for translated PDFs. Configure your own translation/MinerU credentials.

## Upgrade compatibility

Read [docs/UPGRADING.md](https://github.com/Mars-Dingdang/PaperReader/blob/v2.0/docs/UPGRADING.md). Keep existing data paths and `AUTH_SECRET_KEY` when upgrading `feat_fix`. Anonymous v1.0 API clients now need to authenticate. v1.0's in-memory catalog/chat cannot be recovered after shutdown; readable PDF output pairs can be explicitly indexed into a registered account, without modifying the files.

The release is gated on Linux/macOS/Windows backend tests and a Windows executable smoke test covering cookies, upload/read, user isolation, profile/chat persistence and restart. The optional private-paper fixture is skipped when absent. Live paid-provider calls, real-paper translation quality and the interactive Edge UI are outside those automated checks.
