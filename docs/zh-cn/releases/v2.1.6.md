# PaperReader v2.1.6

> 📖 **下载前请先阅读[用户说明书](../../user_instruction.md)**，了解安装、首次配置与日常使用。本页为中文发布说明，英文原文见 [v2.1.6.md](../../releases/v2.1.6.md)。

PaperReader v2.1.6 将 PDF 翻译与 LaTeX 编译改造为可恢复、失败即停（fail-closed）的工作流。

## 可恢复流水线

- 失败文档可通过 `POST /api/document/{id}/retry` 重新排队；归属校验、失败状态检查与重复请求检查原子执行。
- 结构化提取与已校验的翻译 chunk 原子检查点化。更换服务商密钥、Base URL 或模型不会使已校验文本失效；更换源文件或翻译契约会。
- 翻译失败从缺失 chunk 续跑。LaTeX 失败复用已登记的 `translated.tex`，不重复 MinerU 与翻译。
- 应用下次启动时，中断于 `processing` 或 `recovering` 状态的记录转为可重试的失败。

## 更安全的翻译与 TeX

- `<think>` 等 XML/HTML 风格标签被保护为惰性占位符；纯标签段绕过模型，原样保留在论文中。
- 占位符顺序、控制字符、代码围栏、拒答/元评论、异常膨胀与预期外的文档结构逐段校验。批次中单个无效成员只重试该成员。
- 转义的美元货币符号不再形成意外的跨散文数学区域，`Big & Tall` 这类文本会进入单遍文本转义器，渲染为 `Big \& Tall`。
- MinerU `content_list_v2` 将公式标记为 `equation_inline`/`equation_interline`，但会剥掉转义美元符号的反斜杠；存在显式数学时，文本项中的裸 `$` 保持字面量并在渲染时转义，而不是配对成假的内联公式。模型无论如何丢掉 `\$` 转义时，会被确定性地恢复，而不是重新请求模型。
- 真实的 C0 控制字节被移除；`⋆` 渲染为 `$\star$`；预检报告全局大括号、环境、数学定界符、散文 `&`、不安全控制序列与未解析字形，同时保留合法的表格与矩阵。

## 有界 LaTeX 恢复

- 配置的 OpenAI 兼容模型先返回并持久化严格 JSON 的诊断；另一次调用提出精确行区间的补丁。
- 补丁被限制在编译器定位的窗口与文档正文内。非 JSON、重叠或过期补丁、整文档重写、包加载、文件访问与具备 shell 能力的命令一律失败即停。
- 日志锚点只接受编译目标文件名与合理行号，因此文档内植入的 `file.tex:N:` 形态文本无法伪造修复窗口。行号统计遵循 TeX（仅 `\n`），即使散文含 U+2028/U+2029，校验器行号也与编译器锚点对齐。
- 每轮应用补丁都保留 `translated.before-repair-N.tex` 备份与审计记录。每次补丁后重新运行预检与 XeLaTeX，硬性上限两轮。
- 进度面板显示失败阶段/chunk、诊断与修复历史，并禁用重复点击重试。
- 在进入流水线自身错误处理前就死掉的后台任务，现在会把文档标记为失败（可重试），而不是滞留在排队状态。
