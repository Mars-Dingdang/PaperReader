PaperReader v2.0 整合了阅读器 AI 工作流、翻译可靠性与 Windows 可移植版应用。

## 新增内容

- 按用户隔离的 SQLite 历史记录、账号/资料设置、持久化的文档/文献库对话、文献检索与对齐的 PDF 导航。
- 不完整翻译批次恢复、超长段落拆分、改进的 MinerU 图表处理，以及 PDF 编译失败时的安全处置。
- Windows 10/11 x64 可移植版应用，内置 Python 后端与构建好的 React UI；无需单独安装 Python 或 Node.js。
- 面向发布版本的兼容性修复：同源登录 Cookie、PDF/预览凭据、生产环境前端发现与旧版 MinerU 配置。
- 带归属校验的产物下载，不会暴露 SQLite 数据库或共享对话存储。
- 对可恢复的 v1.0 PDF 输出目录提供显式的预览/确认导入，保留既有文件与归属。
- 跨平台回归 CI、真实的打包 EXE 启动/重启检查，以及带版本号的 ZIP 与 SHA-256 校验文件。

## 下载与运行

下载 **PaperReader-v2.0.0-Windows-x64.zip**，用配套的 `.sha256` 文件校验后，将整个压缩包解压到可写目录并运行 `PaperReader.exe`。请阅读包内附带的中文使用说明。EXE 未签名。建议使用 Microsoft Edge；生成译文 PDF 仍需 TeX Live（XeLaTeX/latexmk）。请配置你自己的翻译/MinerU 凭据。

## 升级兼容性

阅读 [docs/UPGRADING.md](https://github.com/Mars-Dingdang/PaperReader/blob/v2.0/docs/UPGRADING.md)。从 `feat_fix` 升级时保留既有数据路径与 `AUTH_SECRET_KEY`。v1.0 的匿名 API 客户端现在需要登录。v1.0 存于内存中的目录/对话在关机后无法恢复；可读的 PDF 输出配对可显式索引进注册账号，且不会修改这些文件。

本版本的发布门禁包括 Linux/macOS/Windows 后端测试，以及覆盖 Cookie、上传/阅读、用户隔离、资料/对话持久化与重启的 Windows 可执行文件冒烟测试。可选的私有论文测试夹具在缺失时跳过。真实的付费服务商调用、真实论文的翻译质量与 Edge 交互 UI 不在这些自动化检查范围内。
