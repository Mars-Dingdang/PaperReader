# PaperReader v2.1.9

> 📖 **下载前请先阅读[用户说明书](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/user_instruction.md)**：安装、首次配置与使用说明。[English release notes](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/releases/v2.1.9.md)

PaperReader v2.1.9 将阅读体验对齐成熟论文阅读器：搜索、批注、位置记忆与联动滚动成为内置能力，AI 回答改为流式并支持引用跳转，PDF 渲染改为按需加载，长文档不再卡顿。

## 新特性

- **文档内搜索（Ctrl/Cmd+F）**。每个 PDF 窗格新增搜索栏，全文（含中文）找出所有命中，显示 x/y 计数，Enter / Shift+Enter 逐个跳转；当前命中会居中并以高亮色区分。
- **持久化批注与 Markdown 笔记导出**。选中文字可加四种颜色高亮并附备注；批注按账号存入 SQLite，重开文档或页面滚回视口时自动重绘，并可导出为双语 Markdown 阅读笔记（原文引用、对齐译文与你的笔记，按页组织）。
- **阅读位置记忆**。阅读器会上报当前页与滚动位置（防抖），重开文档自动回到上次读到的位置。
- **双栏联动滚动**。滚动一侧时另一侧按文档位置同步滚动，可通过工具栏链接图标开关，并有防回环保护。双语对照高亮同时改进：高亮落在与所选语句对应的句子附近，而不是总在块首；多个块包含同一短语时，优先选择距离来源页最近的那一个。
- **图表墙**。解析出的全部图表（MinerU 内容列表或本地解析器的提取检查点）以缩略图条呈现在工具栏中，点击卡片跳转到所在页；LaTeX 项目则列出工程内的插图文件。
- **选中问 AI 与引用跳转**。选中菜单新增"问 AI"：请求携带选中文本，后端先命中所在双语块及相邻块作为优先上下文，再走常规检索。回答通过 SSE 流式输出，[P#] 引用渲染为可点击徽章，点击跳回被引文段（引用指向库内其他论文时会自动切换文档）。
- **跨文档全文搜索**。侧栏新增搜索框，扫描所有已解析文档的原文与译文并列出带上下文快照的命中；点击命中打开文档并高亮对应位置。
- **元数据与 BibTeX 导出**。完成的文档尽力通过 Semantic Scholar 补全标题/作者/年份/期刊（失败不影响流程），显示在侧栏；文档右键菜单可一键导出 BibTeX。自带 `.bib` 的 LaTeX 工程直接提供原文件。
- **按需 PDF 渲染**。滚动模式只挂载视口附近的页面（占位符保持每页精确尺寸，滚动锚定、捏合缩放引擎与页码行为不变）。内存与首屏不再随页数线性增长，缩放只重绘可见页。目录优先使用解析阶段产出的章节结构，缺失时回退到文本层启发式生成。

## 兼容性

向后兼容，无需手动数据迁移：首次启动时 SQLite 为 documents 表新增阅读位置与元数据列，并创建 annotations 表。旧的阻塞式聊天接口与新 SSE 接口并存。生成译文 PDF 仍需 TeX Live 与 `latexmk`（XeLaTeX）。
