# PaperReader v2.1.12

> 下载前请阅读[使用说明](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/user_instruction.md)。[English release notes](../../releases/v2.1.12.md)

v2.1.12 保留 PDF 右键菜单打开时的文字选区，并将 LaTeX 图表缩略图裁剪为图表本身。

## 更新内容

- **保留右键选区**：原文和译文在连续滚动、单页模式下打开右键菜单时，所选文字保持可见。支持普通右键与 macOS Control-click，可继续执行对照定位、问 AI 和添加批注。
- **紧裁剪缩略图**：每个 Figure/Table 预览都从编译后的 PDF 中按标题旁的实际图表裁剪——矢量插图、嵌入图片、多子图组合和 booktabs 表格线——原文与译文 PDF 各自独立定位。无可用图形对象的页面仍回退到原浮动体锚点裁剪。
- **更准的标题定位**：独占一行的标题优先于正文引用（如 "in Table 2."）。当文本提取把子图标签合并进标题行（"…bFigure 2:…"）时，仍能正确找到并裁剪。
- **链路不变**：LaTeX 工程保持每侧一次编译，缩略图不需要额外调用 MinerU。

## 升级

保留原有 `DATA_DIR`、数据库与 `AUTH_SECRET_KEY`。已有账号、批注、密钥、论文和翻译断点继续可用，无需手动迁移数据库。编译 PDF 更新后，已保存的缩略图自动刷新。

## 验证

- Chromium 与 WebKit 浏览器回归通过：双 PDF 栏、连续滚动与单页模式的拖选、右键菜单、问 AI、对照定位、批注备注及 macOS Control-click；前端生产构建通过。
- 新增后端测试覆盖图表标题旁的插图与表格线裁剪（双 PDF 侧）、标题行优先于正文引用，以及子图标签合并进标题行时的兜底定位。全量后端测试与 `compileall` 通过。
- arXiv `2605.18309` LaTeX 压缩包按声明的引擎编译通过；6 个 Figure 和 2 个 Table 在原文、译文中均得到正确页码（2、6、7、8、19、19、20、21）上的紧裁剪缩略图。
- 发布流程运行跨平台后端测试，以及 Windows/macOS 打包和成品启动检查。

## 限制

图形检测依赖嵌入的矢量/图片对象和表格横线。缺少这类对象的浮动体（例如无横线的纯 tabular 排列）回退到原有锚点裁剪或整页预览。本地回归不调用外部 LLM 或 MinerU 服务。
