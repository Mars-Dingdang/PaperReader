# PaperReader v2.1

> 📖 **下载前请先阅读[用户说明书](../../user_instruction.md)**，了解安装、首次配置与日常使用。本页为中文发布说明，英文原文见 [v2.1.md](../../releases/v2.1.md)。

PaperReader v2.1 新增了应用内安全的服务商配置、按账号隔离的 MinerU 设置、原生 macOS 应用，以及聚焦阅读体验的界面改版。

## 新增内容

- 桌面端首次运行时，登录之前会先打开配置向导，收集 LLM 端点、模型、API Key、PDF 解析器、MinerU 选项与视觉模型。
- 随机生成的机器加密密钥与非敏感的引导状态存放在平台的隐藏本地配置文件中。服务商密钥由第一个登录的账号认领，加密存入 SQLite，并从该文件中移除。
- 个人中心现在分为账号、AI 服务与阅读三个标签页。已保存的密钥永不回传浏览器；UI 只接收"已配置/未配置"标志。
- LLM、MinerU、解析器与视觉设置按账号隔离。后台翻译任务使用文档所有者的设置快照。
- Windows 改用原生 WebView2 窗口，不再使用 Edge 应用模式。既有的可移植版 `config.env` 与 `data` 会在首次启动时复制到新的按用户目录，且不删除原文件。
- 全新的 Apple Silicon macOS 13+ 应用包使用 WKWebView，采用 ad-hoc 签名，以带校验和的 DMG 分发。
- 登录支持回车提交，API 错误信息可读，后端不可用时有重试状态，空状态与响应式布局得到改进，并移除了此前偏好设置的保存死循环。
- 前端 bundle 拆分，PDF 与 Markdown 引擎与初始配置/登录 UI 分开加载。

## 下载与运行

### macOS (Apple Silicon)

下载 `PaperReader-v2.1.0-macOS-arm64.dmg` 及其 `.sha256` 文件。打开 DMG 并将 PaperReader 拷贝到"应用程序"。应用为 ad-hoc 签名、未经 Apple 公证，首次启动可能需要在 Finder 中右键 → 打开。生成译文 PDF 仍需 TeX Live。

### Windows

下载 `PaperReader-v2.1.0-Windows-x64.zip`，校验校验和，完整解压后运行 `PaperReader.exe`。需要 Windows 10/11 与 WebView2 运行时；当前的 Windows 系统一般已内置。

两个平台上，首次运行向导都会要求填写用户自己的服务商凭据。发布版无需安装 Python 或 Node.js。

## 升级说明

- Windows v2.0 可移植版的数据/配置在首次启动时导入，并原样保留作为恢复副本。
- 源码安装继续使用 `.env` 默认值。既有账号级 LLM 设置优先；旧的全局服务商凭据会迁移到第一个登录的账号。
- 新的按用户数据库列自动添加。手动迁移已认证的源码安装时，保留既有 `AUTH_SECRET_KEY`。

## 验证

- 40 项后端测试覆盖迁移、加密密钥掩码、首次运行认领、账号隔离、归属校验、翻译行为与解析。
- 前端通过类型检查并用 Vite 构建。
- macOS arm64 应用通过 ad-hoc 签名校验，内嵌服务器/UI 通过完整的打包重启冒烟测试，DMG 校验和已验证。
- tag 发布 CI 在 Linux、macOS、Windows 上重复后端测试，然后构建并对 Windows x64 与 macOS arm64 产物做冒烟测试，最后才发布。
