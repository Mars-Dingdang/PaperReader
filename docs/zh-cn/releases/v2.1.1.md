# PaperReader v2.1.1

> 📖 **下载前请先阅读[用户说明书](../../user_instruction.md)**，了解安装、首次配置与日常使用。本页为中文发布说明，英文原文见 [v2.1.1.md](../../releases/v2.1.1.md)。

PaperReader v2.1.1 改进了 macOS 上的 PDF 阅读，新增安全的整包 LaTeX 工程归档导入，并让视觉校验对新账号与新文档默认关闭。

## 新增内容

- 新账号、新文档与新 TeX 构建默认关闭视觉校验。既有的账号偏好不会被迁移或覆盖；用户仍可在侧边栏或个人中心开启自动/手动校验。
- macOS 桌面应用中 PDF 文本可以选择和复制。既有的基于选区的双语对照导航与高亮保持可用。
- PDF 中内嵌的 HTTP(S) 链接在系统默认浏览器打开，PaperReader 窗口保留当前论文与阅读位置。PDF 内部跳转目标仍在阅读器内导航。
- 触控板捏合缩放响应速度约提升四倍，既有 40%–300% 缩放范围、以光标为中心的缩放与精确百分比输入保持不变。
- 阅读器优先使用 PDF 原生书签。若文本型 PDF 没有书签，会依据章节编号、字号与常见标题（Abstract、Introduction、References、Appendix 等）构建层级大纲。纯图片型 PDF 显示明确的空状态。
- 完整 LaTeX 工程可从 `.zip`、`.tar`、`.tar.gz` 或 `.tgz` 导入。应用依据 `\documentclass`、常见命名与路径深度对主文件候选排序，并等待用户确认主 `.tex` 后才开始解析或翻译。
- 欢迎页、侧边栏与工程导入器会在 arXiv 或出版商提供源码时推荐 LaTeX，因为它通常能更好地保留结构并提升翻译质量。

## 归档安全与限制

解压前先按内容检查归档格式。导入只接受常规文件，拒绝绝对路径或父目录穿越路径、链接、设备条目、加密 ZIP 成员、重复/路径冲突条目、损坏归档以及不含 `.tex` 的归档。限制为单文件 20 MB、整包（含既有文件）200 MB、归档成员 2,000 个。解压分阶段进行，校验或导入失败时回滚。

`POST /api/upload` 仍限于单个 `.pdf` 或 `.tex`。归档客户端应创建项目并把压缩包发送到 `POST /api/project/{project_id}/archive`；其响应保持既有的 `ProjectDetail` 结构，`main_candidates` 按置信度排序。

## 兼容性与升级

- 前端、API、桌面包与发布版本：`2.1.1`。
- Release tag：`v2.1.1`（完整三段版本号；不复用旧的 `v2.1` 短标签）。
- 既有的论文、账号、收藏与显式的视觉校验偏好无需迁移。
- 源码安装应保留既有 `AUTH_SECRET_KEY` 与 `DATA_DIR`；增量式数据库初始化自动执行。

## 下载与运行

### macOS (Apple Silicon)

下载 `PaperReader-v2.1.1-macOS-arm64.dmg` 及其 `.sha256`，校验摘要后打开 DMG，将 PaperReader 拷贝到"应用程序"。应用仍为 ad-hoc 签名且未经 Apple 公证，首次启动可能需要在 Finder 中右键 → 打开。生成译文 PDF 需要 TeX Live。

### Windows

下载 `PaperReader-v2.1.1-Windows-x64.zip` 及其 `.sha256`，校验摘要后完整解压并运行 `PaperReader.exe`。需要 Windows 10/11 与 WebView2。译文 PDF 仍依赖外装的 TeX Live。

## 验证

发布门禁在 Linux、macOS 与 Windows 上运行完整的后端测试套件与 Python 编译检查，外加 TypeScript/Vite 生产构建。tag CI 在发布前构建 Windows ZIP 与 macOS 应用/DMG 并做冒烟测试。

macOS 人工验收覆盖生成与原生大纲、纯图片空状态、触控板缩放、文本选择/复制与双语对照导航，以及内嵌 HTTP(S) 链接的系统浏览器处理。
