# PaperReader v2.1.5

> 📖 **下载前请先阅读[用户说明书](../../user_instruction.md)**，了解安装、首次配置与日常使用。本页为中文发布说明，英文原文见 [v2.1.5.md](../../releases/v2.1.5.md)。

PaperReader v2.1.5 修复了两个可能在对齐步骤后中止结构化（MinerU）PDF 翻译的回归，并将 LaTeX 失败转化为精确、可操作的诊断，同时提供了真正的应用内 TeX 编辑器。

## 修复内容

- **结构化翻译不再因 `'NoneType' object is not iterable` 崩溃。** IR 渲染路径计算了 OCR 数学错误修复记录，但未返回它们，导致流水线在遍历这些记录时，在"Saved N exact bilingual alignment segments"之后立即中止整个文档 —— 此时 LLM 翻译费用已经花掉。`create_translated_tex_from_ir` 现在像其 markdown 对应版本一样返回修复列表，并有回归测试锁定该契约。
- **译文 PDF 不再出现 `Package newunicodechar Error: Invalid argument`。** Unicode 清洗器此前会改写文件中所有映射字符 —— 包括导言区 `\newunicodechar{□}{...}` 声明，其第一个参数必须保持为单个字面字符。替换它（如替换为 `$\square$`）会破坏编译。`sanitize_and_repair` 现在按 `\begin{document}` / `\end{document}` 拆分完整文档，只改写正文；同一保护也覆盖手动重新编译端点（它清洗用户的完整文档）。
- **中文数学讲义端到端验证通过。** `testexamples/Lec1-数列极限.pdf`（《高等数学》第一讲：实数列的极限）现在能完成完整流水线 —— MinerU VLM 提取、316 个结构化块、682 个双语对齐段、OCR `\sqrt` 修复、XeLaTeX 编译 —— 产出 22 页译文 PDF，零 `Missing character` 警告。

## 新增内容

- **可操作的 LaTeX 编译诊断。** 致命错误从 TeX 日志解析并带源码行号（`L123: ...`），缺失字形聚合后给出替换建议（`□ (U+25A1) x4 -> replace with $\square$`）。编译失败现在报告出错行而非原始 `latexmk` 尾部日志；编译成功时若存在渲染为空白的字符会给出警告。
- **带审计记录的 OCR 数学错误修复。** MinerU 偶尔把 `\sqrt[k]{a_n}` 读成 `\sqrt[{k}/{a_n}]`（被开方数被吞进根指数）或根指数未闭合；两种形态都会自动修复，且每次修复都记录行号，可在 TeX 编辑器中核对。
- **应用内 TeX 编辑器（CodeMirror 6）。** 译文 `translated.tex` 支持语法高亮、查找替换（Ctrl+F / Ctrl+H）以及从编译错误面板跳转行号；也可以在系统文件管理器中显示或在 VS Code 中打开。手动重新编译成功即可挽回此前流水线失败的文档。
- **CJK 文档的证明符号安全网。** 中文讲义常见字符（□ ■ ● ○ ★ ✓ ✗ 及经 CJK 字体路由的符号区）映射到 `amssymb` 命令或 CJK 字体，译文文档编译不再出现空白字形。

## 兼容性

这是向后兼容的补丁版本，无需数据迁移。保留既有 `DATA_DIR`、`SQLITE_DB_NAME`、`AUTH_SECRET_KEY`、账号数据库与用户设置。平台要求不变（Windows 10/11 x64 带 WebView2；macOS 13+ Apple Silicon；译文 PDF 生成需 TeX Live 的 `latexmk` 与 `xelatex`）。
