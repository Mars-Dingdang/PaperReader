PaperReader v1.0 冻结了此前 main 分支的 `dd21e24438b11844e964e2ad038b1917c3b835c3` 提交（"fixed autocheck and sidebar bugs and enabled dark mode"）。

这是最初的源码/Web 版本：支持 PDF 与 TeX 上传、MinerU 解析、LLM 翻译、双语 PDF 阅读、上下文对话、视觉校验与深色模式。历史源码保持不变，可通过该 tag 与 `release/v1.0` 分支访问。

v1.0 不包含 Windows 应用。其文件目录保存在内存中；账号化持久存储与 Windows 可移植版属于 v2.0。升级前请阅读[升级指南](../../UPGRADING.md)。
