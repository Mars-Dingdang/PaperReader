# PaperReader v2.1.7

> 📖 **下载前请先阅读[用户说明书](../../user_instruction.md)**，了解安装、首次配置与日常使用。本页为中文发布说明，英文原文见 [v2.1.7.md](../../releases/v2.1.7.md)。

PaperReader v2.1.7 修复了 macOS 桌面应用中译文 PDF 的编译问题，并解决了用真实 PDF 输入复现出的 LaTeX 生成与恢复故障。

## 修复内容

- **从 Finder 启动的 macOS 构建可以运行 XeLaTeX。** 当 `LATEXMK_PATH` 为绝对路径时，PaperReader 现在会将其所在目录加入编译器子进程的 `PATH`。检测到的 `/Library/TeX/texbin/latexmk` 因此能启动同目录的 `xelatex`，而不是报 `sh: xelatex: command not found`。
- **生成的中文文档使用可移植字体。** PaperReader 禁用 `ctex` 过时的平台预设，显式选择 SimSun、Songti SC、PingFang SC、Noto Serif CJK SC 或 FandolSong。重试既有 v2.1.6 失败时，会先升级其已保存的 `translated.tex` 再编译，并复用已完成的提取与翻译检查点。
- **本地文本层提取保持畸形公式示例可编译。** 货币金额与故意畸形的行间公式示例保留为转义散文，而不是被配对成无效的嵌套 LaTeX 定界符。
- **PDF 数学字形被规范化。** PDF 字体编码中拆开的私有用区括号片段转换为普通括号，`≪`、`ℓ`、撇号与取整定界符获得 LaTeX 映射，不再渲染为缺失字形。
- **strict 构建成功不再因字体警告被丢弃。** 翻译引入的 Unicode 替换标记（U+FFFD）在检查点与 TeX 生成前被移除。其他缺失字形诊断仍作为编译警告可见；只有致命日志错误或需要宽松 `-f` 编译的 PDF 才进入自动恢复。
- **最小修复补丁容忍邻近行号漂移。** 若模型给出的原文完全一致而行号有偏移，只要在编译器定位的错误窗口内存在唯一逐字匹配，PaperReader 就会重新定位；含糊或窗口外的编辑仍被拒绝。

## 兼容性

这是向后兼容的补丁版本，无数据库或数据迁移。译文 PDF 生成仍需带 `latexmk` 与 XeLaTeX 的 TeX Live。
