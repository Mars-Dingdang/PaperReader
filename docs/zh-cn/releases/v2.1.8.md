# PaperReader v2.1.8

> 📖 **下载前请先阅读[用户说明书](../../docs/user_instruction.md)**，其中包含安装、首次运行的服务商配置与使用说明。English release notes: [docs/releases/v2.1.8.md](https://github.com/Mars-Dingdang/PaperReader/blob/main/docs/releases/v2.1.8.md)

PaperReader v2.1.8 将 LaTeX 链路与 PDF 链路对齐：多文件 TeX 项目被完整翻译，翻译过程逐片段上报进度，失败后从断点恢复而不是从头重来。

## 新特性

- **多文件 TeX 项目被完整翻译。** 上传的 arXiv 压缩包在翻译前先做扁平化——`\input`/`\include` 文件被递归内联（被注释的引用和无法读取的目标保持原样）。此前管线只读主 `.tex` 文件，像 SafeMCP 这种正文几乎全部在 `sections/*.tex` 的论文，"译文" PDF 仍然是整篇英文。
- **LaTeX 翻译逐片段上报进度并落盘断点**，与 PDF 链路对齐。运行中进度标签显示"翻译 n/m 个片段"，每翻完一个片段立即写入 `translation-checkpoint.json`；失败重试只补缺失的片段——原始 TeX 不再重编译，已翻译片段不会重翻。占位符按 token 键恢复，中文语序带来的占位符换位被接受，而丢失引用仍会触发校验。
- **正文注释在翻译前剥离，纯注释行整行删除。** 被注释掉的草稿文本本来就不会出现在编译后的 PDF 里，但此前它们会被分块送给 LLM；当模型把草稿中携带的引用占位符一并丢掉时，分块校验失败、整篇翻译中止。纯注释行如果只被清空会留下空行——空行即 `\par`，出现在 `tcolorbox` 选项块内会直接杀死 pgfkeys，因此整行删除。
- **环境命令与数学一样受保护。** `\begin{...}`/`\end{...}` 以占位符 token 形式通过翻译并被校验，模型无法再悄悄丢掉环境开括号、让后续所有 `\end` 配对错乱（在 `figure*` 和自定义 `tcolorbox` 环境上实际复现过）。
- **会议样式可以在 XeLaTeX 下编译。** `aaai2027.sty` 这类样式会加载 iftex 并用 `\RequirePDFTeX` 终止编译，部分还调用 pdfTeX 专有的 `\pdfinfo` 原语；译文 preamble 先加载引擎测试、解除门禁并提供 `\pdfinfo` no-op。CJK 字体设置现在紧跟 `\documentclass` 加载——先于会议字体包——因为 `newtxtext` 会破坏 fontspec 对其后声明字体的按名解析。psnfss 系 Times 包（`times`、`mathptmx`、`txfonts`）的 Type1 度量会触发 `XeTeXglyph` 错误，已替换为外观等价的 `newtxtext`。
- **模型产物的确定性修复**：删除多余的闭花括号（`\url{https://...}.}`），转义文本模式下裸的下划线（源 `user\_instruction` 被译成 `user_instruction`），重排后紧跟 `\\` 的 `[` 行不再被当作行距参数解析。`alignedat` 环境也不再触发"裸 &"预检告警。

## 同一版本中的其他改动

- **参考文献不再送翻译**（PDF 链路）：References/Bibliography 标题之后的内容（以及 MinerU 的 `reference_list` 块）保持英文，既方便检索文献也节省翻译预算。
- **术语一致性。** 每篇文档做一次尽力而为的术语提取：论文标题和常用术语表会注入每个翻译批次，同一个词在摘要和结论里译法保持一致。该步骤任何失败都会静默跳过，不阻塞翻译。
- **启动自愈经过端到端验证**：应用退出时停留在 `processing` 的文档会在下次启动时被标记为可重试失败，通过"从此处重试"从断点恢复。
- **上传改为流式写盘**（1 MiB 分块），不再把整个文件读进内存。
- **缺少 API Key 时抛出明确异常**，而不是返回一个可能被当作译文下游传递的错误字符串。
- 移除了 Nougat 时代的 "Problem 1/2" 标题修复逻辑——它只适配某一特定的课程作业版式，却在此前的每次 PDF 处理中都会执行。

## 兼容性

向后兼容，无数据库或数据迁移。生成译文 PDF 仍需要带 `latexmk` 与 XeLaTeX 的 TeX Live。

## 验证

- `DreamGuard.tar.gz`（AAAI 2027 样式，主文件 77 KB + 附录）端到端翻译通过：20/20 片段、逐片段进度可见；译文 PDF 在 XeLaTeX 下越过样式的 pdfTeX 门禁编译成功，零缺字，14 页共提取 11,940 个中文字符。
- `SafeMCP.tar.gz`（主文件仅 5.8 KB，约 195 KB 正文在 `sections/*.tex`）扁平化后端到端翻译通过；23 页共提取 15,787 个中文字符、零缺字，而此前版本输出的是未翻译的英文。一次翻译中途被强杀的运行，被启动清扫标记为可重试失败，手动重试后从断点完成。
- 后端回归测试（181 个用例）与前端生产构建全部通过。
